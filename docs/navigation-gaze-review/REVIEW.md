# 点击行程与提前抬头复核

## 设计

章节位置、原生滚动距离、高度曲线、材质、纹理、光照、PSR 与文案版式保持不变。改动只有点击导航的时间分配与下降视线。

点击不再使用浏览器内建的 smooth scroll。统一滚动导演在 RAF 中推进真实页面滚动位置，DOM 与 WebGL 继续读取同一个进度。沿叙事路径积分平滑密度，将下降、离地与近地运动分配更多时间；时长为 `1800 + 15000 × 加权行程` 毫秒。加权行程是感知距离，不是地理米数。全程使用 `6t⁵−15t⁴+10t³`，首尾速度和加速度为零，密度区间之间不另设停顿。

| 点击路径（反向相同） | 计划时长 |
|---|---:|
| 01 遥望 → 02 月面档案 | 10.50 秒 |
| 02 月面档案 → 03 立于月面 | 12.59 秒 |
| 03 立于月面 → 04 永久阴影 | 8.38 秒 |
| 04 永久阴影 → 05 观测交汇 | 4.80 秒 |
| 05 观测交汇 → 06 回望月光 | 4.20 秒 |
| 01 遥望 → 03 立于月面 | 21.29 秒 |
| 01 遥望 → 06 回望月光 | 33.26 秒 |

原有视觉阻尼保留；低帧率下单帧时间最多推进 250 ms，后台恢复不会跳过数秒。实际软件渲染截图耗时可能高于计划时长。滚轮、触摸、指针、导航键与 Escape 可中断；重新选择章节从当前可见进度起算；减少动态效果仍立即直达。

## 验证记录

截图由真实 Chrome / Playwright 生成，使用 SwiftShader 软件 WebGL。`descent` 与 `descent-reverse` 保存下降正反向序列；`clicks` 保存实际点击动画的连续截图，并记录每个 RAF 的镜头位置、朝向、高度和单一球体状态。PNG 是间隔采样，不宣称每个显示帧都保存一张 PNG。

动态点击录制使用 CDP `Page.captureScreenshot(captureBeyondViewport:false)` 直接捕获视口。初次试录发现 Playwright 默认文档裁切在持续滚动时会因坐标过时导致整幅截图偏移；试录已丢弃，正式证据使用视口捕获。

### 已完成的逐张目视检查

- 桌面正反向下降：各 21 张，20%–53.5% 叙事进度，抬头区间以 1% 为主加密采样。40% 已见地平线；41% 地球在上缘进入；42%–45.5% 地球逐渐下移；最后几十米地平线与地球相对姿态稳定，只有地形逐渐靠近。
- 12 条实际点击路径：01→02→03→04→05→06→05→04→03→02→01→03→01。107 张 PNG（含各段终点）、706 帧 RAF 记录。已逐张查看联系表，并查看关键帧原图；没有双球穿插、突然抬头或新增贴地黑斑；PSR 斑块和六幕文案均正常。
- `clicks/audit.json`：全部帧保持一个月球、一个相机、相机位于地表以上。每条路径从首次 `running` 开始到停稳均无进度反冲。采集启动到实际 click 之间仍有上一行程的微小阻尼尾段，因此审计明确排除了这些点击前 idle 帧。
- 动态截图的软件渲染实际耗时：01→03 为 41.29 秒，反向 38.81 秒；计划均约 21.29 秒。此差异来自 SwiftShader 低帧率、截图开销、单帧推进上限与终点阻尼，不代表硬件加速浏览器的精确耗时。
- 原生滚动距离与高度曲线没有变化；最终贴地姿态完全相同。高程、影像、法线、PSR 和光照文件均未修改。
