因此，本轮恢复的是“细碎、地理表面上的分布层”这种视觉表达，不把旧程序化噪声追认为科学冰图。

## 最终数据方案

采用 [NASA PGDA / LOLA 产品 90](https://pgda.gsfc.nasa.gov/products/90) 中 1531 个面积大于 1 km² 的 PSR 多边形；源 DEM 间距 20 m，页面显示栅格约 303 m/px。PSR 是地形推导的永久阴影，不是水冰探测、冰稳定性温度图或基础模型预测。更小的阴影区未纳入，不能称为完整 PSR 目录。

原始南极立体投影直接由球体经纬度重建；南纬 80–90° 范围内使用同一地理位置采样。边界不会随屏幕或相机漂移。PSR 覆盖保留原多边形内洞，不用噪声伪造，也不扩大区域。颜色、边界内侧强调、经纬细线属于艺术处理，图注、页脚和数据弹窗分别注明。

同源 `LDEM_80S_80MPP_ADJ_HILL.TIF` 提供 80 m 源像素的模拟晕渲（太阳高度 / 方位各 45°），通过 COG overview 按范围读取，重采样到同一显示网格并打包进 B 通道。它是制图底图，不作为实时物理光照或冰检测；图注明确标注。

原始 SHP 约 20 MB，仅用于离线派生；不放入浏览器包。显示资产、来源 URL、哈希和重建脚本均随项目提交。

## 场景设计与约束

- 全球基础网格与按需加载的精细网格使用相同 PSR 材质逻辑、相同纹理，继续任意时刻只显示一个月面。
- 月表路径 `p≤0.68` 保持原样。极区观察只在内部叙事 0.68–0.84 生效，原生滚动映射没有变。
- 相机位置以球心径向方向插值与对数半径插值靠近南极；视线持续看向插值中的月面目标，上方向用四元数平滑过渡，避免位置 / 朝向独立插值导致月球退出画面。起止权重和一阶导数归零，可正反向沿原路径衔接。
- 极区展示压低原金色扫描网格，保留较细、低亮度的极区经纬参照；退出后下一幕恢复原金色网格。
- 第 04 幕文字在放大观察期间延长停留，随后淡出；其余幕锚点及月表节奏不变。

## 资源与重建

网页只增加一张 2048²、约 3 MB 的 RGB 打包 PNG；R 为真实多边形覆盖，G 为内部边界强调，B 为 LOLA 模拟晕渲。作为共享纹理复用，按 RGBA8 加 mipmap 保守估算约 21.3 MiB，不新增场景、球面或全屏 HDR 缓冲。资源在全程共享缓存中保留；原 NAC 按需加载与离开释放逻辑不变。

重建先运行 `scripts/prepare-polar.py`（pyshp 2.3.1 / Pillow 11.3.0 / numpy 2.3.3），再运行 `scripts/prepare-polar-relief.py`（另需 rasterio 1.4.3）。离线 Python 包在独立临时环境安装，没有修改项目 npm 依赖或用户 yarn.lock。

历史 Git 时间：初版 2026-09-25 21:40:33；04c35f5 为同日 22:27:58；2401762 为同日 23:50:12；1c39556 为 2026-09-26 00:50:44，均 UTC+8。`git diff 9bb949d 04c35f5 -- src/scene/shaders.ts` 为空，证实这两版的原极区 shader 完全相同。

## 本轮亲眼检查后修正的问题

- 第一轮 PSR 已替换蓝晕，但金色扫描网格压过青蓝数据层；改为极区幕内压低扫描网格，保留低亮度经纬参照。
- 全球彩色底图放大后偏平，科学区与坑地形不易一起阅读；加入同源、同投影的 LOLA 模拟晕渲并如实标注。
- 晕渲在整月远景过早出现，像圆形贴片；改为远景显示 PSR 斑块，随相机靠近才连续显出晕渲。晕渲外缘渐变，不扩张实际 PSR 覆盖。
- 初次完整正向序列发现 85–86% 月球滑到屏幕上方；改为相机持续跟踪同一月面的移动目标，修复后 85 / 86 / 87 / 88% 实测月球均留在画面。新增中心视锥约束测试防止回归。
- 手机 81% 图已亲眼确认：地图在上、文字在下，完整图注与导航没有遮挡。

`check*` 文件夹是这些中间迭代，不作为最终交付截图。`forward/`、`reverse/` 才是最终全序列。

[投影控制点记录](projection-check.json)：用 GDAL 独立核对 6 个经纬控制点与 shader 的投影公式，双精度计算差异小于 1e-6 m；这验证公式与轴向，不代表源数据达到该测量精度。
