## Scientific distinction

The 0.6 m pixel size and 2 m elevation post spacing describe NAC source data, not model accuracy. Cropping, resampling, level of detail and reduced mobile imagery remain disclosed. The PSR map is terrain-derived, not an ice detection or model output. The site runs no model inference. Artistic Earth direction, procedural rocks, simulated relief, colour, outlines and scan guides remain identified.
